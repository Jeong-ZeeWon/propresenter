# ProPresenter 6 파일 생성기

텍스트를 입력하면 ProPresenter 6에서 바로 열 수 있는 `.pro6` 파일을 생성하는 정적 웹 앱입니다.

## 실행 방법

별도의 빌드 과정이 필요 없습니다. 정적 파일 서버로 `index.html`을 열면 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## 사용 방법

1. 텍스트 영역에 가사/본문을 입력합니다.
2. 슬라이드 구분 방식을 선택합니다.
   - **빈 줄로 구분**: 빈 줄로 나뉜 각 문단이 하나의 슬라이드가 됩니다.
   - **한 줄 = 한 슬라이드**: 비어있지 않은 각 줄이 하나의 슬라이드가 됩니다.
3. `#그룹이름` 으로 시작하는 줄을 넣으면 이후 슬라이드들이 해당 이름의 그룹(예: 1절, 후렴)으로 묶입니다.
4. 글꼴, 글자 크기, 정렬, 색상, 화면 비율 등을 설정합니다.
5. "`.pro6` 파일 생성 및 다운로드" 버튼을 누르면 파일이 다운로드됩니다.
6. 다운로드한 `.pro6` 파일을 ProPresenter 6에서 열거나 라이브러리로 드래그하면 됩니다.

## 입력 예시

```
#1절
주 하나님 지으신 모든 세계
내 마음 속에 그리어 볼 때

#후렴
주님의 위대하심을
내 영혼이 찬양하네
```
